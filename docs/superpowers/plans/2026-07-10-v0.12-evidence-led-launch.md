> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship and promote `v0.12.0-alpha` with reproducible evidence that omnireach is a faster read-only agent path than starting browser automation, while preserving its logged-in Chinese-platform advantage.

**Architecture:** Add a standalone benchmark harness that drives the real stdio MCP server and real Playwright/Chrome paths, emits raw JSON, and renders the public report from those samples. Package the measured result with synchronized version metadata, bilingual README proof, a real terminal recording, release notes, channel-specific copy, and an auditable launch baseline before publishing through GitHub and authenticated community accounts.

**Tech Stack:** Python 3.10+, stdlib subprocess/JSON/statistics, omnireach MCP, Playwright Python package with system Chrome, pytest, Hatch/uv, VHS/ffmpeg, GitHub CLI, OpenCLI Chrome bridge.

Create `scripts/benchmark_read_path.py` with these public helpers and concrete behavior:

```python
MIN_TEXT_LENGTH = 500
DEFAULT_URL = "https://www.rfc-editor.org/rfc/rfc9110.html"


def validate_text(text: str) -> None:
    if len(text.strip()) < MIN_TEXT_LENGTH:
        raise RuntimeError(
            f"retrieved fewer than {MIN_TEXT_LENGTH} text characters"
        )


def summarize_samples(samples: list[float]) -> dict[str, object]:
    if not samples:
        raise ValueError("at least one benchmark sample is required")
    rounded = [round(value, 2) for value in samples]
    return {
        "median_ms": round(statistics.median(rounded), 2),
        "min_ms": min(rounded),
        "max_ms": max(rounded),
        "samples_ms": rounded,
    }


def send_message(proc: subprocess.Popen[str], message: dict[str, object]) -> dict:
    assert proc.stdin is not None and proc.stdout is not None
    proc.stdin.write(json.dumps(message, separators=(",", ":")) + "\n")
    proc.stdin.flush()
    line = proc.stdout.readline()
    if not line:
        stderr = proc.stderr.read() if proc.stderr is not None else ""
        raise RuntimeError(f"MCP process exited before responding: {stderr}")
    return json.loads(line)


def mcp_fetch(proc: subprocess.Popen[str], url: str, request_id: int) -> str:
    response = send_message(proc, {
        "jsonrpc": "2.0",
        "id": request_id,
        "method": "tools/call",
        "params": {
            "name": "omnireach_fetch",
            "arguments": {"url": url, "backend": "http", "timeout": 60},
        },
    })
    if "error" in response:
        raise RuntimeError(f"MCP error: {response['error']}")
    result = response["result"]
    if result.get("isError"):
        raise RuntimeError(f"omnireach_fetch failed: {result}")
    text = result["structuredContent"]["content_markdown"]
    validate_text(text)
    return text
```

Add `start_mcp()`, `stop_mcp()`, `benchmark_mcp_cold()`, and
`benchmark_mcp_warm()` using `[sys.executable, "-m", "omnireach", "mcp"]`. Cold timing
starts before `Popen` and stops after one validated tool response. Warm timing starts only
around `mcp_fetch()` on a previously initialized process. Close stdin and require exit code
zero after every session.

- [ ] **Step 4: Implement the real Playwright boundary and report renderer**

In the same script, import Playwright only inside the browser functions:

```python
def read_with_page(page, url: str) -> str:
    response = page.goto(url, wait_until="domcontentloaded", timeout=60_000)
    if response is None or not 200 <= response.status < 400:
        status = None if response is None else response.status
        raise RuntimeError(f"Playwright navigation returned status {status}")
    text = page.locator("body").inner_text(timeout=60_000)
    validate_text(text)
    return text


def ratio(numerator: float, denominator: float) -> str:
    return f"{numerator / denominator:.1f}x"
```

`benchmark_playwright_cold()` starts `sync_playwright()`, launches
`p.chromium.launch(channel="chrome", headless=True)`, creates one page, validates its text,
and closes the browser for every measured sample. `benchmark_playwright_warm()` launches one
headless Chrome process, performs one untimed warm-up navigation, then opens and closes one
page per measured sample.

`render_report()` must render the four measured medians, cold and warm ratios, raw-data link,
environment table, method, and this exact limitation sentence:

```text
This read-only retrieval benchmark does not compare clicks, forms, downloads, or visual testing.
```

The CLI accepts `--url`, `--repeat`, `--json-out`, `--markdown-out`, and
`--skip-playwright`. It writes files atomically through sibling `.tmp` files, prints the
JSON payload to stdout, and exits nonzero on any short/failed response.
