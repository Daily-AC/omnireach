This release makes Omnireach's machine-facing contracts fail honestly and recover usefully.

## What changed

- Fetch now rejects short verification and login-wall placeholders. The real Reddit `Please wait for verification` response is recorded as `captcha_suspected`, never returned as successful content, and includes a logged-in `opencli reddit read` fallback.
- CLI usage errors are emitted as a JSON error envelope on stdout whenever `--json` is present.
- `--sources` is now an alias for `--on`, matching the MCP argument name.
- Browser-backed heavy sources default to 60 seconds for cold starts. An explicit `--timeout` now overrides every selected source instead of being silently ignored.
- CLI and MCP search accept `--profile` / `profile` to select an OpenCLI Browser Bridge profile without mutating the parent environment.
- Doctor runs the real `opencli doctor` probe, detects multiple connected profile conflicts, reports Google correctly, and checks the native Douyin bridge before evaluating its OpenCLI fallback.

## Real verification

- 373 tests passed.
- A live Reddit search returned normalized OpenCLI results with `errors=[]` using an explicit profile.
- A live Reddit fetch rejected the verification wall with exit 1 and empty content; the suggested OpenCLI fallback then returned the real post and comments.
- A live doctor run reported the current multiple-profile conflict for OpenCLI sources while correctly keeping the connected native Douyin bridge healthy.
- The final wheel and sdist passed `twine check`; the wheel started in an isolated environment as `0.15.0-alpha`.
