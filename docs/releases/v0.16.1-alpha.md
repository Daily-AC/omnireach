This hotfix makes native multi-source search reliable.

## Fixed

- Serialize native bridge jobs before binding the fixed authenticated localhost port.
- Keep queued jobs cancellation-aware.
- Preserve the existing extension 0.2.8 protocol, permissions, and short-lived background-tab behavior.

## Root cause

The dispatcher runs selected sources concurrently, while each native adapter previously tried to bind its own server to `127.0.0.1:19826`. Single-source calls passed, but multi-source calls let only the first job start and returned `Address already in use` for the rest.

## Verification

- 378 Python tests and 12 JavaScript extension tests passed.
- A forced-native Google + X + Xiaohongshu search returned all three sources with `adapter=native-chrome` and `errors=[]`.
- Wheel and sdist passed `twine check`.

uv tool install --force "omnireach==0.16.1a0"
