This release removes OpenCLI from the primary search path for every browser-backed source and adds an experimental grounded-search backend through an authenticated agy session.

## What changed

- Google, Reddit, Twitter, Xiaohongshu, TikTok, and Douyin now search through the Omnireach native Chrome bridge first. OpenCLI remains an automatic compatibility fallback.
- Native searches use short-lived background tabs in the existing Chrome profile. Extension 0.2.8 adds command/version negotiation, cold-start-safe offscreen initialization, deterministic cleanup, and no `windows` permission.
- TikTok now extracts real rendered result cards instead of relying on an unstable private endpoint. Twitter derives missing authors from canonical status URLs.
- The experimental `agy` source reuses an authenticated dedicated conversation and its server-side grounded WebSearch citations. Configure it with `omnireach agy configure <conversation-id>` and call it explicitly with `--on agy`.
- Doctor, setup metadata, the bundled skill, and both READMEs now describe the native-first transport accurately.

## Real verification

- 377 Python tests and 12 JavaScript extension tests passed.
- Forced-native live searches returned normalized results with `errors=[]` for all six browser sources.
- A live agy grounded search returned three citations with `adapter=agy-grounded-search` and `errors=[]`.
- Wheel and sdist passed `twine check`; an isolated wheel install reported `0.16.0-alpha` and 17 registered sources.

## Install or upgrade

```bash
uv tool install --force "omnireach==0.16.0a0"
```

Run `omnireach bridge install`, reload the unpacked extension once in `chrome://extensions`, then verify with `omnireach bridge status --json`.
