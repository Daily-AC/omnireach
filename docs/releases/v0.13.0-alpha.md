# v0.13.0-alpha - Google and connected Twitter in normal search

Normal `omnireach search` now adds Google and Twitter/X when OpenCLI is installed. Both
sources reuse the connected Chrome profile through background ephemeral tabs and close them
after each command. `--mode quick` remains browser-free, and explicit `--on` remains exact.

## Why this path

Direct HTTP requests to Google Search returned a JavaScript challenge rather than a usable
SERP in real testing. Google's Custom Search JSON API is closed to new customers and is
being discontinued for existing customers. The OpenCLI Chrome path returned real Google
results without adding a persistent visible tab, requires no new Python dependency, and
matches Omnireach's existing login-state boundary.

## Verification

The release is verified against real upstream responses with:

```bash
omnireach search --on google --limit 5 --json "gpt5.6"
omnireach search --on twitter --limit 5 --json "gpt5.6"
omnireach search --limit 5 --json "gpt5.6"
```

The automatic result envelope must contain both `google` and `twitter`, with no errors for
either source. Visible Chrome window and tab counts are recorded before and after the
automatic search and must remain unchanged.

## Install Or Upgrade

Install the CLI and Claude Code skill:

```bash
curl -fsSL https://raw.githubusercontent.com/Daily-AC/omnireach/main/install.sh | sh
```

Install only the v0.13 CLI from PyPI:

```bash
uv tool install --force 'omnireach==0.13.0a0'
```
