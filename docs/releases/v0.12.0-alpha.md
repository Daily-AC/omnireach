# v0.12.0-alpha - MCP before Playwright for read-only web work

Omnireach now gives agents a standard, dependency-free MCP fast path for search and page
reading. It is intentionally narrower than browser automation: use it before Playwright for
read-only work, then keep Playwright for interaction and visual verification.

## What Changed

- Added `omnireach_search` and `omnireach_fetch` as model-controlled MCP tools.
- Added the dependency-free `omnireach mcp` stdio server and Claude plugin registration.
- Extracted shared search and fetch services so the CLI and MCP use one typed contract.
- Kept ordinary page fetches on the built-in HTTP extractor with Jina fallback, without
  starting Chrome.
- Kept login-backed sources on the user's existing Chrome session through OpenCLI's hidden,
  ephemeral tab.
- Fixed CAPTCHA detection falsely rejecting legitimate articles that mention Cloudflare.
- Added a reproducible benchmark harness, raw samples, and generated report.

## Measured Read-Path Result

The release benchmark reads the same RFC 9110 document five times through each path on
macOS arm64, Python 3.12.13, Playwright 1.61.0, and system Chrome 149.0.7827.201.

| Path | omnireach MCP | Playwright + headless system Chrome |
|---|---:|---:|
| Cold process median | **1383.86 ms** | 3749.26 ms |
| Warm runtime median | **1311.46 ms** | 1687.94 ms |

Playwright took 2.7x the omnireach time on the cold path and 1.3x with both runtimes warm.
The [full method and limitations](https://github.com/Daily-AC/omnireach/blob/main/docs/benchmarks/read-path-v0.12.md)
and [raw JSON](https://github.com/Daily-AC/omnireach/blob/main/docs/benchmarks/read-path-v0.12.json)
are committed with the release.

This is a page-retrieval benchmark, not a browser-automation benchmark. Playwright's warm
browser cache remains enabled, and failed responses abort the run instead of being omitted.

## Chrome And Login State

Ordinary HTTP and HTTPS pages do not start Chrome. Sources that require a real logged-in
session, such as Xiaohongshu, may use the existing Chrome profile through a hidden ephemeral
tab. The tab is released after the call; credentials and cookies are not copied into
omnireach output.

## What Omnireach Does Not Replace

Keep Playwright or another browser-control tool for clicks, forms, uploads, downloads,
screenshots, visual assertions, and unsupported interactive workflows. Omnireach replaces
the unnecessary browser step for supported search and read operations, not the browser
automation category.

## Install Or Upgrade

Install the CLI and Claude Code skill:

```bash
curl -fsSL https://raw.githubusercontent.com/Daily-AC/omnireach/main/install.sh | sh
```

Install the CLI only from PyPI:

```bash
uv tool install --force omnireach
```

Register the MCP server manually when the client does not load the plugin:

```json
{
  "mcpServers": {
    "omnireach": {
      "command": "omnireach",
      "args": ["mcp"]
    }
  }
}
```
