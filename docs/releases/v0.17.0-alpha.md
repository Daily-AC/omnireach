# v0.17.0-alpha — Media parsing foundation

Omnireach now gives agents a bounded media contract alongside search and fetch.

## Added

- `omnireach media inspect <url>` for normalized YouTube, Bilibili, and direct-media metadata.
- `omnireach media parse <url>` for caption-first transcript artifacts without downloading the full video.
- `omnireach_parse_media` over MCP with structured errors and stable `MediaEnvelope` output.
- Direct-media sidecar VTT, SRT, JSON3, and Bilibili BCC parsing.
- SHA-256-addressed metadata, subtitle, transcript JSON/Markdown, and manifest artifacts.
- `doctor` probes for `yt-dlp` and `ffprobe`.

## Backend behavior

- YouTube uses `yt-dlp` for metadata and caption discovery.
- Bilibili uses its anonymous official read API by default, avoiding common yt-dlp HTTP 412 failures.
- Direct audio/video URLs use `ffprobe`.
- Signed caption URLs and browser credentials are never persisted in envelopes or manifests.

Deep ASR and keyframe extraction are intentionally deferred to a later release.
