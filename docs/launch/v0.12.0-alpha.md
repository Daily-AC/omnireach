## Response Bank

### Does this replace Playwright?

No. It is the read-only fast path for search and URL-to-Markdown. Keep Playwright for clicks,
forms, file transfer, screenshots, visual assertions, and unsupported dynamic workflows.

### Does it open Chrome tabs?

Ordinary page fetches do not start Chrome. Login-backed adapters may create a background,
ephemeral tab through OpenCLI, then release it. The recorded Xiaohongshu run left the visible
Chrome window count unchanged.

### How is login state handled?

The OpenCLI bridge asks the user's existing Chrome session to make the request. Omnireach does
not ask for the account password and does not include cookies or credentials in tool output.

### Does it bypass every anti-bot system?

No. Public HTTP paths can still be blocked, and login-backed sites can require CAPTCHA or
change their internal APIs. Omnireach reports those failures and keeps browser automation as
a fallback; it does not promise universal bypass.

### Is OpenCLI still required?

Only for sources that need the user's browser login state. Hacker News, RSS, WeChat search,
Bilibili, ordinary fetch, and configured API boosters do not require OpenCLI. The base wheel
does not depend on it.

### Is the benchmark fair?

It measures one narrow operation: retrieve readable text from the same public document.
Playwright uses installed Chrome in headless mode and keeps its warm browser cache enabled.
Every sample, version, content-size check, and command is public. It says nothing about
interactive browser tasks.

### How do I install it?

For the CLI and Claude Code skill:

```bash
curl -fsSL https://raw.githubusercontent.com/Daily-AC/omnireach/main/install.sh | sh
```

For the CLI only:

```bash
uv tool install omnireach
```
